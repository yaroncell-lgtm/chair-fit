# כושר בוקר מהכיסא · גרסה 5

אימון בוקר של 10–20 דקות על כיסא, בלי מכשירים: בטן ומותניים, ידיים כתפיים וטרפז, כוח ושריפה.
מותאם לטלוויזיה (דפדפן LG, ניווט בשלט), לאייפון ולמחשב.

- עד 5 פרופילים, לכל אחד רמה, יעד שבועי, מוזיקה, בעיות שיש להתחשב בהן, מועדפים, הישגים ורצף.
- הנחיה קולית וספירה בעברית (Web Speech), מוזיקה מסונתזת בקצב (האוס / אירובי / זומבה) והחזרות מסונכרנות לביט.
- הדגמות מאוירות נטענות ישירות מ-chairsensei.com (לא מאוחסנות כאן), ולכן דורשות חיבור לאינטרנט.

קבצים: `index.html`, `app.css`, `ex.js` (ספריית התרגילים והימים), `app.js` (הכול חוץ מהנתונים), `sw.js` (מטמון; להעלות את VERSION ואת `?v=` בכל שחרור).

לשימוש אישי. אין לראות בתוכן ייעוץ רפואי.
